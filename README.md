# Deyby Josue | Software Specialist Portfolio 🚀

Este es mi portafolio profesional, una experiencia web interactiva y moderna construida para mostrar mis habilidades en desarrollo de software, proyectos y trayectoria.

![Portfolio Preview](/src/assets/logo_white_rct.png)

## ✨ Características

- **Diseño Futurista e Interactivo:** Una interfaz inmersiva inspirada en diseños "Cyberpunk" y "Tron", con animaciones fluidas y efectos de luz ambiental.
- **Micro-interacciones:** Sonidos de escritura, efectos de iluminación dinámica y un sistema de carga personalizado.
- **Habilidades Dinámicas:** Un sistema de visualización de habilidades con detalles específicos mediante modales interactivos.
- **Easter Eggs:** Incluye sorpresas interactivas como una carrera de píleles estilo "Tron" y juegos clásicos (Game of Life, Konami Code).
- **Totalmente Responsivo:** Optimizado para una experiencia fluida tanto en computadoras de escritorio como en dispositivos móviles.

## 🛠️ Stack Tecnológico

### Frontend
- **Vite:** Herramienta de compilación ultra rápida para el desarrollo moderno de aplicaciones web.
- **Vanilla JavaScript (ES6+):** Lógica central potente y desacoplada de frameworks pesados para un rendimiento óptimo.
- **CSS3 Moderno:** Uso extensivo de variables, animaciones clave y técnicas de diseño responsivo sin dependencias externas.
- **HTML5 Semántico:** Estructura de contenido limpia y SEO-friendly.

### Especialidades del Desarrollador (Deyby Josue)
- **Backend:** C#, .NET Core, ASP.NET MVC.
- **Base de Datos:** SQL Server.
- **Móvil:** Flutter.
- **Metodologías:** SCRUM, Arquitectura de Cebolla (Onion Architecture).

## 📁 Estructura del Proyecto

```text
Deb_Portfolio/
├── src/

│   ├── data.js       # Fuente de datos centralizada del portafolio.

```

## 🚀 Inicio Rápido

Para ejecutar este proyecto localmente, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Josidkk/Deb_Portfolio.git
   ```

2. **Navegar al directorio del proyecto:**
   ```bash
   cd Deb_Portfolio
   ```

3. **Instalar dependencias:**
   ```bash
   npm install
   ```

4. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

5. **Abrir en el navegador:**
   Visita `http://localhost:5173` (o el puerto indicado en la consola).
